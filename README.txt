# Word Sprint 500 — PWA 배포 파일

## 포함 파일
- index.html : 앱 본체
- manifest.webmanifest : PWA 설치 정보
- sw.js : 오프라인 캐시/서비스 워커
- icons/icon-192.png : PWA 아이콘
- icons/icon-512.png : PWA 아이콘

## 배포 방법
1. 이 폴더 전체를 HTTPS로 서비스되는 웹호스팅에 업로드합니다.
2. 주소를 iPhone Safari에서 엽니다.
3. Safari의 공유 버튼 → '홈 화면에 추가'를 선택합니다.
4. 홈 화면의 Word Sprint 500 아이콘으로 실행합니다.

## 중요
- PWA는 ZIP 파일을 휴대폰에 직접 설치하는 방식이 아닙니다.
- HTTPS 웹주소에서 설치해야 합니다.
- GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 올릴 수 있습니다.
