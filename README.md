# Word Sprint - 이미지 광고 업로드 버전

## GitHub Pages 배포
1. ZIP 파일의 **내용물 전체**를 GitHub 저장소의 최상위(root)에 업로드합니다. `index.html`이 저장소 최상위에 있어야 합니다.
2. GitHub Pages에서 배포된 사이트를 새로고침합니다. 기존 버전이 보이면 브라우저 캐시를 지우거나 비공개 탭에서 확인하세요.
3. 관리자 메뉴에 로그인한 뒤 광고 이미지 옆의 파일 선택 버튼을 누르고 휴대폰 사진 앱에서 캡처 이미지를 선택합니다.
4. 광고 클릭 링크를 입력하고 광고 설정 저장을 누릅니다.

광고 이미지는 브라우저 로컬 저장소에 저장됩니다. 다른 휴대폰과 자동 공유하려면 클라우드 동기화가 별도로 필요합니다.
